# Blackridge Mortgage Regime Lab v3

This revision fixes the two issues visible in the screenshots:

1. The application now uses nearly the full browser width instead of a 1,320-pixel centered container. Side margins are reduced to 14 pixels.
2. The cast introduction no longer mixes HTML wrappers with separate Streamlit image nodes. Each cast profile is rendered as one compact HTML card with a 72-pixel circular editorial sketch, eliminating the empty boxes and badly cropped horizontal strips.

The video, expression-specific dialogue portraits, compact analytical scenes, assignment downloads, and self-contained data model are retained.
